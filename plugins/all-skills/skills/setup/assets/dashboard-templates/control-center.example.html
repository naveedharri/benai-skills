Capabilities

Two jobs, one clean line

Every skill and scheduled task does one of two jobs. One set keeps the second brain current, the other does the sales work itself. The line: if it changes what the OS knows, it logs. If it just acts, it does not.

The master guide skill that builds the whole OS from an interview. It sits apart from the two working sets because it stands the system up rather than runs the sales.
