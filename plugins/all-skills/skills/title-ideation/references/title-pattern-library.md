# Title Pattern Library (naming aid only)

Use these names when labeling structure patterns in Phase 4 and Option Set B, so runs stay comparable. This file is NOT a generator and NOT a data source. A pattern only counts if it shows up in the fresh last-20-to-25 pull; never propose a pattern from this list without recent evidence.

| Pattern name | Shape | Example shape |
|---|---|---|
| Stop/Instead | Stop X, do Y instead | "Stop Writing Prompts, Do This Instead" |
| Percent-Wrong | N% of people do X wrong | "99% of People Use Claude Wrong" |
| Only-One | The only X you need | "The Only AI Workflow You Need" |
| N-Things | N tools/skills/mistakes | "8 Claude Skills I Can't Live Without" |
| Time-Boxed | X in N minutes/days | "Build an AI Agent in 15 Minutes" |
| First-Person Proof | I tried/built/tested X | "I Automated My Whole Business" |
| Contrarian Call-Out | X is dead / you don't need X | "You Don't Need n8n Anymore" |
| Everything-Changed | X just changed Y | "Claude Just Changed Automation Forever" |
| Beginner Path | How to start X from zero | "How to Start With AI Agents (Beginner Guide)" |
| Versus | X vs Y, which wins | "Claude vs ChatGPT for Automation" |
| Hidden/Secret | The X nobody talks about | "The Claude Feature Nobody Talks About" |
| Level-Up | From X to Y | "From Zero to AI Power User" |

Naming rules:

- If a pulled title mixes two patterns, label it with the dominant one and note the second in parentheses.
- If a recurring structure has no name here, add a row with a short kebab-style name and keep using it.
- Time claims in Time-Boxed titles must match the video's real runtime (core rule 10).
