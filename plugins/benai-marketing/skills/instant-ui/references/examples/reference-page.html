Section 01 · The Problem

Brand drift happens
one shortcut at a time.

The BenAI system only works if everyone using it sticks to the same tokens, the same type ramps, and the same components. Drift kills the look faster than anything else.

Drift 01

Soft shadows sneak in

Someone replaces the hard 6px offset with a blurred rgba shadow and the brutalist look dies. Always use 6px 6px 0 #111.

Drift 02

Rounded corners appear

A dev adds border-radius: 12px because it "feels modern." It feels generic. Keep corners square.

Drift 03

Google Fonts get imported

Someone pulls in Inter or Space Grotesk. The BenAI brand uses system fonts. Period.

Section 02 · The System

Three rules do all the work.

If you remember these three, you can't get the brand wrong. Everything else is a variation on them.

01

Cream bg, slate ink

Page background is #fffef8. Ink is #111. Pure white only appears inside cards and input fields.

Color · Foundational
02

Hard borders, hard shadows

3px solid #111 everywhere. 6px 6px 0 #111 drop shadow. No blur, no radius, no softness.

Layout · Structural
03

Gradient stripe on every page

4px tall. Blue to green to amber. The one part of the brand that is truly non-negotiable.
