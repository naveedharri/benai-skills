## The folder map

| Folder | Holds |
| --- | --- |
| `Context/` | offer, ICP, process, positioning, voice, the rep, the stack, config |
| `Lead-Gen/` | outbound campaigns, cadences, the lead-gen SOP |
| `Deals/` | one file per active deal, plus the metrics file |
| `Calls/` | one file per sales call: summary, notetaker link, score |
| `Templates/` | proposal, one-pager, and other masters |
| `Intelligence/` | the monthly and quarterly reports |
| `Daily/` | the rolling task list and the per-day routine logs |
| `Skills/` | the manifest of installed routines and skills |

## Conventions

The full rules live in the `CLAUDE.md` files. In short: every piece of information has one home, brain-update routines log and actions do not, one deal file per prospect frozen on close, sales calls stored as summary plus link, every entity wikilinked, no em dashes.
