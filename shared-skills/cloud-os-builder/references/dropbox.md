# Dropbox — Cloud OS

## Topic
- Independent cross-platform cloud; the desktop app syncs a local folder.
- "Smart Sync / online-only" placeholders, like OneDrive's Files On-Demand.
- Best-supported consumer cloud for mobile via the Remotely Save plugin.

## Advantages
- Most reliable cross-platform sync engine.
- Real local copy on desktop; good version history (rollback).
- Mobile actually works via the free Remotely Save community plugin.

## Disadvantages
- Tiny free tier (2 GB).
- Native folder sync doesn't work on Obsidian mobile → must use Remotely Save.
- Online-only files can break vaults; conflict copies; no Dropbox MCP connector.

## How to set up
Desktop:
1. Install the Dropbox desktop app, sign in.
2. Create the OS folder inside the Dropbox folder.
3. Set it to "Make available offline" / Local.
4. Drop in the shared structure (`templates/`).

Mobile:
5. In Obsidian mobile, install + enable the Remotely Save plugin.
6. Choose Dropbox, authorize, and sync.
