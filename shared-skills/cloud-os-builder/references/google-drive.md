# Google Drive — Cloud OS

## Topic
- Google's cloud storage; the desktop app syncs a local folder to the cloud.
- Cross-platform on desktop; keeps real local copies via Drive for Desktop.
- Alternative path: a community sync plugin, but the desktop app is the main way.

## Advantages
- Most free storage of the consumer clouds (15 GB).
- Real local copy on desktop → Claude / Obsidian read & write normally.
- Familiar, widely used; has a Drive MCP connector.

## Disadvantages
- Sync delay; not realtime, not multiplayer.
- Conflict copies on simultaneous edits.
- Not native on Obsidian mobile.

## How to set up
1. Install Google Drive for Desktop, sign in.
2. Create the OS folder inside the Drive folder.
3. Set the folder to "Available offline" (no online-only placeholders).
4. Drop in the shared structure (`templates/`).
5. Repeat on other desktops; accept the sync delay.
