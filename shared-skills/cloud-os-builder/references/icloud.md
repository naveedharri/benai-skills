# iCloud — Cloud OS

## Topic
- Apple's cloud; Apple-only ecosystem.
- Move the OS folder into the iCloud Drive folder from Finder.
- Changes sync near-realtime, but still with a delay.

## Advantages
- Near-realtime sync; built into Apple devices, no extra app.
- Real local copy on Mac.
- The one consumer cloud Obsidian mobile supports natively on Apple devices.

## Disadvantages
- Apple-only; no MCP connector.
- Still a sync delay; weak conflict resolution.
- Apple's own design guidance and the Obsidian forum caution against heavy use.

## How to set up
1. Enable iCloud Drive in Settings.
2. Create / move the OS folder into the iCloud Drive folder (Finder).
3. Drop in the shared structure (`templates/`).
4. On iPhone / iPad, open the same folder via the Obsidian iOS app.
