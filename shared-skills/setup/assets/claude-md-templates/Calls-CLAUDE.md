# Calls

One file per sales call. The record of what was said, so the OS can score it, follow up on it, and learn from it.

## Conventions

- **Sales calls only**, identified by the attendees (an external prospect plus the rep), not by the calendar title, which is rarely standardized.
- **One file per call**, named `YYYY-MM-DD-Prospect.md`.
- **Store the summary plus the {{notetaker_name}} link, never the full transcript.** The transcript lives in the notetaker; the file holds the distilled record.
- **Score first calls only.** Score from the full transcript, not the summary, and confirm the rep actually ran the call before scoring them.
- The score uses the rep's dimensions and weights from `Context/config.md`.

Link each call file to its deal. No em dashes. Structural changes here update the root `MAP.md`.
